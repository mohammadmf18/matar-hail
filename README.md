# مطر حائل PWA

تطبيق ويب تقدمي باللغة العربية يعمل على هاتف هونر وأجهزة أندرويد.

## النشر المجاني
1. فك ضغط الملفات.
2. ارفع **محتويات المجلد** إلى مستودع GitHub عام، ثم فعّل GitHub Pages من Settings > Pages > Deploy from a branch > main / root. أو ارفع المجلد إلى Netlify Drop.
3. افتح رابط HTTPS الناتج في متصفح Chrome على هونر.
4. من قائمة ⋮ اختر «إضافة إلى الشاشة الرئيسية» ثم «تثبيت» إذا ظهر الخيار.

## الحدود التقنية
- يعرض بيانات حقيقية من Open-Meteo ويحدّثها أثناء فتح التطبيق كل 5 دقائق.
- إشعار الجهاز اختياري ويعمل فقط عندما يكون التطبيق مفتوحًا وبإذن الإشعارات؛ **لا توجد إشعارات خلفية أو خادم دفع**.
- بيانات الهطول ليست رادارًا مباشرًا ولا تمثل تحذيرات المركز الوطني للأرصاد.
- يمكن فتح واجهة التطبيق دون إنترنت بعد تحميلها أول مرة، لكن لا يمكن تحديث الطقس دون اتصال.

## خريطة الأمطار
- خريطة تفاعلية مدمجة من Windy لتوقعات الأمطار والسحب بنموذج ECMWF، مع شريط زمني وتغيير المنطقة.
- توقعات 24 ساعة وثلاثة أيام من Open-Meteo، وقد تختلف عن الخريطة لاختلاف المصدر.
- الخريطة ليست رادار رصد مباشر، وتحتاج اتصالًا بالإنترنت.

## الرادار الفعلي
- العرض الافتراضي: صور الرصد السابقة من RainViewer، آخر ساعتين بفاصل 10 دقائق، مع تشغيل الحركة ووقت الإطار وتحديث القائمة كل 5 دقائق أثناء فتح العرض.
- وقت الإطار هو وقت تجميع الصورة، وليس ضمانًا لوقت التقاط الرادار المحلي. تحذير عند تأخر آخر إطار أكثر من 30 دقيقة أو تعذر التحميل.
- قناع التغطية المنشور لا يبين الأعطال اللحظية؛ غياب ألوان الهطول لا يؤكد عدم وجود أمطار.
- توقعات الأمطار والسحب منفصلة في Windy، والبطاقات في Open-Meteo.
- الخرائط الأساسية OpenStreetMap؛ عرض الخريطة باستخدام Leaflet 1.9.4 من CDN مع التحقق من SRI.
- RainViewer API للاستخدام الشخصي والتعليمي، دون ضمان توفر؛ لا تُخفى نسبة المصدر.
